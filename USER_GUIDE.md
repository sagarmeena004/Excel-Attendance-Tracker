# 📘 Excel Attendance Tracker - User Guide

## 📌 Introduction

This guide explains how to use the Excel Attendance Tracker
to manage and monitor attendance records.

## 🚀 Getting Started

1. Download the Excel file from this repository.
2. Open `attendence sheet.xlsx` in Microsoft Excel.
3. Navigate to the attendance tracking sheet.
4. Review the employee names and attendance columns.

## 📅 How to Mark Attendance

1. Find the employee's name in the attendance table.
2. Locate the required day (Monday to Saturday).
3. Use the checkbox to mark attendance.
4. Repeat the process for other employees.

## 📊 Attendance Progress

- Attendance progress is displayed using visual data bars.
- Progress bars help compare attendance records.
- The dashboard provides a quick attendance overview.

## 🛠️ Requirements

- Microsoft Excel
- A computer capable of opening XLSX files

## 💡 Tips

- Save the workbook after updating attendance.
- Keep a backup of important attendance records.
- Avoid deleting formulas or formatting.
- Verify attendance entries before saving.
