# 📊 Excel Attendance Tracker

A professional Excel-based Attendance Management System designed to track daily attendance and visualize attendance progress.

## 🚀 Features

- Daily attendance tracking (Monday to Saturday)
- Checkbox-based attendance management
- Automatic attendance progress visualization
- Conditional formatting
- Organized attendance dashboard
- Employee attendance records
- User-friendly Excel interface

## 🛠️ Technologies Used

- Microsoft Excel
- Excel Formulas
- Conditional Formatting
- Data Bars
- Excel Checkboxes

## 📁 Project Structure

```text
attendence excel/
├── attendence sheet.xlsx
└── README.md
```

## 📊 Project Overview

This project provides a simple and effective way to manage attendance records using Microsoft Excel.

Users can mark attendance using checkboxes and monitor attendance progress through visual data bars.
