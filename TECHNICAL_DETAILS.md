# 📊 Excel Attendance Tracker - Technical Details

## Project Overview

The Excel Attendance Tracker is a spreadsheet-based
attendance management project.

## Technologies Used

- Microsoft Excel
- XLSX Workbook Format
- Excel Checkboxes
- Conditional Formatting
- Data Bars
- Cell Formatting

## Attendance Tracking

The workbook provides a structured table for recording
attendance from Monday to Saturday.

Attendance values are represented using TRUE/FALSE.

## Dashboard Design

- Green-themed attendance dashboard
- Organized rows and columns
- Visual attendance indicators
- Attendance progress bars

## Workbook Features

### 1. Checkbox Controls
Checkboxes provide an interactive way to mark attendance.

### 2. Conditional Formatting
Conditional formatting helps display attendance information
visually.

### 3. Progress Visualization
Data bars provide a visual representation of attendance
progress.

## File Information

**Workbook:** `attendence sheet.xlsx`

**File Format:** `.xlsx`

**Project Category:** Excel Attendance Management
