# 📁 Excel Attendance Tracker - Project Structure

## Project Overview

This repository contains an Excel-based attendance tracking system
along with documentation for understanding and using the project.

## Directory Structure

```text
attendence excel/
│
├── attendence sheet.xlsx
├── README.md
├── FEATURES.md
├── USER_GUIDE.md
├── TECHNICAL_DETAILS.md
├── PROJECT_STRUCTURE.md
└── .gitignore
```

## File Descriptions

### attendence sheet.xlsx
Main Excel workbook used for attendance tracking.

### README.md
Provides the project introduction, features, and technologies.

### FEATURES.md
Describes the main features of the attendance tracker.

### USER_GUIDE.md
Explains how to use the attendance tracking workbook.

### TECHNICAL_DETAILS.md
Contains technical information about the Excel project.

### PROJECT_STRUCTURE.md
Explains the repository structure and file organization.

### .gitignore
Prevents temporary Excel and system files from being tracked.

## Project Goals

- Maintain organized attendance records.
- Provide an easy-to-use Excel attendance tracker.
- Keep project documentation accessible.
- Maintain version history using Git and GitHub.
